# Lessons

- 在判断 GPU 暴露和映射状态时，优先依据容器内的证据，不要把宿主机截图和容器截图混为一谈。
- 在改模型输入链路前，先用本地源码或已安装包确认接口支持范围，不要凭经验假设只能走文件路径。
- 改“文件路径 -> 内存输入”时，要同时检查 AutoModel 外层和 remote_code 内层的接受类型；这次 Fun-ASR 外层能吃 bytes，但自定义模型实际只接受 `str` 和 `torch.Tensor`。
- 做“速度优化”时，如果改了 speaker 归属或对齐链路，要把精度回归单独验证；不要把“ASR 变快”误当成“切分和声纹路径没动”。
- 做大规模名单选择 UI 时，先按 100+ 选项场景评估信息密度；平铺复选框在会议参会人场景下不可扩展，优先用可搜索多选下拉并用 tag 回显已选项。
- 当前端缓存的数据依赖后端地址时，必须在地址切换时显式失效缓存和已选状态；不要让旧后端的名单继续参与新后端请求。
- 上传音频链路不要假设 `librosa.load(BytesIO(...))` 和上层模型都兼容所有格式/输入类型；内存解码要有文件路径回退，Paraformer 之类的整段 ASR 也要先确认是否实际接受路径字符串。
